# Tower Defense 3D

3D-игра в жанре Tower Defense в **одном HTML-файле**. Процедурная low-poly графика на Three.js, без сборки и сервера — открыл файл в браузере и играй.

## Возможности

- **Карта 16×12** с S-образной дорогой (3 поворота), базой и порталом входа, 22 слотами для башен.
- **5 типов башен** (лёд, огонь, молния, яд, пушка) × **3 уровня** улучшений с уникальными эффектами: замедление, AoE и горение, цепная молния, яд со стаками, разрывные снаряды.
- **5 типов монстров**: слизь, бегун, гигант (броня), летун (летит над картой, неуязвим для пушек), дракон-босс.
- **Бесконечные волны** с честной прогрессией сложности: HP ×(1+0.1N), скорость растёт с 20-й волны, каждая 10-я волна — босс.
- **Экономика**: награда только за убийство, улучшения, продажа башен с возвратом 50% вложений.
- **Полный игровой цикл**: постройка, улучшение, продажа, HP-бары, кольца дальности, эффекты частиц, всплывающие суммы наград, пауза и ускорение 1x/2x, экраны старта и game over.
- **Встроенные автотесты**: `index.html?test=1` — самопроверка игровой логики в консоли (`TEST PASS`).

## Управление

| Действие | Как |
|----------|-----|
| Вращение камеры | перетаскивание мышью / один палец |
| Зум | колесо мыши / пинч |
| Постройка башни | клик по пустому слоту → выбор башни |
| Управление башней | клик по башне (улучшить / продать) |
| Пауза | пробел или кнопка в HUD |
| Скорость | 1x / 2x в HUD |

## Как запустить

Просто откройте `index.html` в браузере (Chrome/Edge/Firefox). Сервер и сборка не нужны.

Для запуска автотестов: `index.html?test=1` — результаты появятся в консоли браузера.

## Технические детали

- **Three.js r184** через CDN (import map, jsdelivr) — без npm и без локальных файлов.
- Все модели — процедурные low-poly из примитивов Three.js, без внешних ассетов.
- `requestAnimationFrame` + delta-time; скорость игры масштабирует движение, стрельбу и таймеры.
- Таргет 60 FPS при 60+ монстрах: кеширование геометрий/материалов, пулы частиц и снарядов.
